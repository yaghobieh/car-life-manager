# Privacy

Data minimization: store only what the product needs for the current vehicle file.

| Data | Why | Source | Retention |
| --- | --- | --- | --- |
| Session user id | Authorization | Generated locally | Until cookie cleared |
| Public vehicle record | Vehicle profile | data.gov.il | Until user deletes the vehicle |
| Tasks / expenses / reminders | Product features | Generated or user-entered | Until deleted |
| Government ID | Not stored | — | — |

Users can delete a vehicle and its child records. No third-party parking/toll/insurance data is ingested today.
