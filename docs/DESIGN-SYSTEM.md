# Design system

RTL-first Hebrew SaaS: navy sidebar, white cards, blue accent `#2F6BFF`, light gray canvas, 14px radii, restrained shadows.

Forge usage:

- Bear: `BearProvider` (RTL), buttons/inputs where they fit, future primitive adoption
- Grid Table: vehicles, tasks, expenses
- Harbor: API shell, health, rate limit, request log

Custom product components: `Logo`, `CarArt`, `EmptyState`, `StatusBadge`, application shell.

Status is never color-only — badges include Hebrew text.
