# Domain model

Core entities: `User`, `Vehicle`, `Task`, `Expense`, `VehicleDocument`, `MaintenanceRecord`, `Reminder`, `AuditLog`, `IdentityVerification`.

Vehicle fields are limited to what public MOT data or the user can justify. Ownership “hand” is stored only when officially available (currently not in the public registry record we map).

Tasks are generated by `generateVehicleTasks(vehicleContext)` in `@clm/shared`, not hardcoded in React.
