# Product

Car Life Manager is a long-term Israeli vehicle-ownership dashboard.

Tagline: **Everything you need for your car. In one place.**

Primary journey: add a plate → official lookup → vehicle file → “what do I need to do next?” → expenses over time.

Hebrew is the primary UI language. English localization is a future i18n layer, not hardcoded copy.

The product never presents mock expenses or fake “connected” parking/toll accounts as real user data.
